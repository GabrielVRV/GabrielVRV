# Gabriel Viaro

Desenvolvedor Full Stack na CASP (Amparo, SP). Trabalho com integrações ao ERP TOTVS Datasul: APIs REST em Progress ABL / OpenEdge 12.8 no backend e telas em React + TypeScript no frontend. Fora do ERP, uso Python (FastAPI) para ferramentas internas e automação.

Portfólio com prints dos sistemas em produção: [gabrielvrv.github.io](https://gabrielvrv.github.io)

## Stack

**Backend:** Progress ABL / OpenEdge 12.8, TOTVS Datasul, Python, FastAPI, Node.js (Express)
**Frontend:** React, TypeScript, Vite, AngularJS (legado em migração)
**Banco:** PostgreSQL (pgvector), SQL Server, MySQL, SQLite
**Infra e qualidade:** Docker, GitHub Actions, pytest, Ruff, mypy, ESLint
